# ABCLOUD 后台管理插件操作指南

本指南适用于 121 测试站 `https://66.yunxnet.cn/` 的魔方财务 3.7.6。站点物理目录沿用旧名称，但浏览器只访问 `66.yunxnet.cn`。使用现有魔方管理员账号登录；插件不另设账号、密码或数据库连接。主题切换仍由站点管理员自行处理。

## 进入后台

1. 在魔方财务后台的“插件管理”中找到“ABCLOUD 首页内容管理”，确认已安装并启用。
2. 打开插件菜单“ABCLOUD 首页管理”。控制台显示各内容模块数量和最近操作。
3. 修改后刷新 `https://66.yunxnet.cn/` 查看效果。浏览器可直接访问 `/abcloud/content` 查看公开的只读数据；后台写接口必须保持登录状态。

## 内容管理

| 模块 | 主要操作 | 首页位置 |
| --- | --- | --- |
| 轮播图管理 | 新增、编辑、删除；选择图片或视频、PC/移动端图片、文字主题、按钮、跳转方式、显示状态和排序；“全局设置”调整切换和速度 | 首屏轮播 |
| 快捷入口管理 | 标题、描述、图标、链接、显示状态和排序 | 轮播下方五卡片区域 |
| 顶部导航管理 | 设置标题、链接、父级 ID、菜单类型、推荐标签和排序；父级 ID 为 `0` 表示一级导航，最多三级 | 桌面导航和移动菜单 |
| 底部导航管理 | 按分类建立链接并排序 | 页脚导航 |
| 通用模块 | 编辑分类、标题和内容 JSON；“侧边导航”可设置客服头像、QQ、工单和二维码，“底部菜单”可设置页脚分组 | 侧边客服、二维码和页脚 |
| 弹窗通知管理 | 编辑标题、富文本、按钮链接和“每次显示/仅显示一次” | 网站通知弹窗 |
| 网站配置 | 站点名称、Logo、联系方式等首页配置 | 页头和页脚对应区域 |
| 资源库管理 | 建目录、进入目录、上传图片/视频、重命名、删除和选择文件 | 为其他模块提供资源 URL |
| 操作日志 | 查询近期操作 | 仅后台 |

资源库上传支持 JPG、PNG、GIF、WebP、MP4 和 WebM，单文件上限为 20 MB。编辑表单中的“选择资源”会打开资源库窗口，选中后填入资源路径。远程上传仅接受公开 HTTPS 地址，不跟随跳转。

## 编辑顺序与注意事项

1. 先在资源库上传轮播图、图标或二维码，再到内容模块新增记录并选择资源。
2. 顶部导航的商品菜单继续使用财务系统原生商品分组和商品 ID；不要把导航链接当作商品数据。新闻、业务公告和文档也继续使用财务原生来源。
3. 插件安装后，未编辑的模块保留当前首页内容。某模块第一次保存或删除后由插件接管；若把该模块记录全部删除，首页会按“主动清空”处理。例如清空所有轮播会隐藏轮播区。
4. 轮播设置为视频时仍建议填写移动端备用图片。弹窗选“仅显示一次”后，同一浏览器会记住该弹窗 ID；要复看可用新的浏览器会话或清理该站点的本地存储。
5. 保存后打开匿名窗口检查首页、移动端和资源链接。若 `/abcloud/content` 请求失败，首页会保留原主题的既有内容；这只能说明回退生效，不能代替插件验收。

插件的发布、备份与实际验收记录见 [适配契约与验收](适配契约与验收.md)。不要通过直接修改财务业务表来填充插件展示内容。
